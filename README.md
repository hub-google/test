# TableFlow 前端展示頁

獨立撰寫的餐飲營運平台概念展示網站，參考餐飲 SaaS 常見的公開功能類別，包含預約管理、候位叫號、線上訂餐、顧客 CRM、營運分析與多門市管理。**不是 inline 官方網站，也不是從 inline 下載的 HTML、CSS 或 JavaScript。**

## 檔案

- `index.html` — 網站首頁與各功能段落
- `styles.css` — 響應式樣式與介面排版
- `app.js` — 功能分頁切換與手機選單
- `.github/workflows/pages.yml` — GitHub Pages 發布工作流程

## 查看

預計 GitHub Pages 網址：<https://hub-google.github.io/test/>

如果尚未啟用 Pages，至儲存庫 **Settings → Pages → Build and deployment → Source → GitHub Actions**，再重新執行 **Deploy static site to GitHub Pages** 工作流程。
